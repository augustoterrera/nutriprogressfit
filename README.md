# NutriProgressFit

Herramienta de trabajo para nutricionistas independientes: pacientes, planes alimentarios con asistencia de IA y seguimiento diario del paciente.

- `PRODUCT.md`: qué es el producto, para quién y sus restricciones.
- `NutriProgressFit_V12_corregido.html`: prototipo original del concepto.

## Desarrollo

Requisitos: Node.js 20.9 o superior y npm.

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).
